# dont-panic-website

This is the source code behind the website [https://dont-panic.eu](https://dont-panic.eu), built with [Astro](https://astro.build).

## B Corp Transparency Notice

The source code for dont-panic.eu is public to maintain our commitment to governance, accessibility, and operational transparency. For usage rights, please refer to our [LICENSE](LICENSE) file.

## Development

```bash
npm install
npm run dev
```

Other available scripts:

- `npm run build` — build the production site
- `npm run preview` — preview the production build locally
